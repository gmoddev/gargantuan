# Public Luau API audit

Audited against the integrated `main` base `2a4c1d2b03e40178b97334bb6f1f2eeedd51fe9f` on 2026-11-14. This audit covers the authored `docs/src/content/docs/api/` pages and `docs/examples/`; it does not claim exhaustive member documentation.

## Evidence and corrections

- `assets/classes/*.luau` and `assets/services/*.luau` are the canonical class/service declaration input. Checked native global and datatype registration in `src/scripting/ScriptEngine.cpp`, `LibInstance.cpp`, and `src/animation/AnimationTrack.cpp`. Cross-checked selected calls with `src/classes/WorldRootQueries.cpp`, `RemoteEventBase.cpp`, `RemoteFunction.cpp`, `Animator.cpp`, `src/services/AssetService.cpp`, and `src/network/RemoteLuau.cpp`.
- Checked tested usage and bounds in `tests/PhysicsBackendTests.cpp`, `AnimationFoundationTests.cpp`, `FirstCompleteGameTests.cpp`, `FoundationTests.cpp`, and network gameplay fixtures. Current authority/lifecycle context came from `ScriptSecurity.md`, `PlayerRuntime.md`, `PhysicsBackend.md`, `LuauRuntimeSurface.md`, and network contracts, resolved against implementation when stale.
- `LuauRuntimeSurface.md` had stale claims that broad queries/filters and assets/animation were absent. Those scoped paragraphs and the native globals list were corrected against bindings. The whole older inventory remains Unverified until a complete prose review; its verification date was not mechanically advanced.
- `IsPropertyModified()` is an unconditional `true` stub in `src/classes/Instance.cpp`, despite its declared semantic description. The reference explicitly marks the limitation. Commented-out `WaitForChild`, `BindChildren`, and similar entries in `Instance.luau` are excluded.
- `ClearAllChildren()` destroys direct children and their subtrees (`Instance.cpp`), rather than merely unparenting them. `StepPhysics` is a generated Luau binding with `MutateDataModel` and Main authority checks; its current native implementation ignores the declared `Instances` argument (`WorldRoot.cpp`).
- Cast misses return nil, while empty overlap results retain read-only `Parts` and `Truncated` fields (`WorldRootQueries.cpp`). AssetService rejects non-string and over-256-byte references before a lookup (`AssetService.cpp`); FileLink import is a startup-time compatibility source mount, not a general live sync/write API (`SourceMount.md`).
- Direct service access and `GetService` share lazy singleton behavior; `FindService` does not construct. Remote direction, provisional peer identity, timeout terminals, and supported argument types are derived from current native code, not from the future networking architecture page alone.
- No public declaration was found for gameplay `DataStore`, generic `game:Save()` / `game:Load()`, or arbitrary file access. Persistence is described as native saved-property/package behavior, not invented Luau calls.
- Native VM registration is independently routed in `api/datatypes-and-globals.mdx` from `ScriptEngine.cpp` and `Lib*.cpp`; value-only `AnimationTrack`, `EnumItem`, `Rect`, and `SignalConnection` are distinguished from constructor globals. `LibTask.cpp` registers `cancel`, `synchronize`, and `desynchronize` as explicit not-implemented errors.
