# Native BlockGrid cell field and binary dataset

The grid owns signed integer cells. Air is implicit. The private 8³ leaves use a single value for uniform occupancy, sorted index/value pairs for at most 64 occupied cells, and dense values for mixed higher occupancy. Stone and Brick have stable definition IDs 1 and 2. ID 0 is air and accepts only orientation 0. Occupied cells accept 24 proper cube orientations, with 0 as identity. Data has no per-cell Instance, worker or simulation tick.

Coordinates range from −1,048,576 through 1,048,575. A half-open maximum can equal 1,048,576. Edits admit up to 1,024 commands and 32,768 cumulative visits. The field caps live pages at 16,384, occupied cells at 1,048,576 and its encodable dataset at 16 MiB. All checks happen before installation. A changed command batch advances one data revision. A rejected batch or one that restores its original state preserves the old data and revision. Immutable page payloads allow existing snapshots to keep their own contents.

An optional synchronous provider admission sees the exact candidate through an overlay of the prior directory and prepared changes. A provider can read a candidate cell, enumerate candidate pages, or inspect changed pages including removals. The overlay expires as the callback returns. Installation moves prepared nodes and releases old references. Provider denial keeps the prior source intact.

Studio-origin cell edits enter the ordinary DataModel transaction history. Only that path captures the changed coordinates' before/after block values, budgets their retained vector capacity and honors implicit or explicit transaction ownership. Repeated commands targeting one position produce one semantic difference. Undo and redo validate each expected current cell before applying any differences. A changed touched cell rejects replay, while edits outside the touched set survive. Replay submits one bounded atomic cell patch, including up to 32,768 individual restored values. Gameplay placement allocates no authoring inverse.

The little-endian dataset starts with ASCII `BGRD`, version byte 1 and an unsigned 32-bit leaf count. Leaves appear in ascending signed Z, Y, X order. Each begins with three signed 32-bit X, Y, Z origin coordinates aligned to 8 and a one-byte storage tag. A block record is a 16-bit definition and 8-bit orientation. Tag 0 carries one occupied uniform block. Tag 1 carries a 16-bit count and strictly increasing 16-bit local offsets paired with occupied block records. Tag 2 carries 512 blocks in X-fastest order. Empty pages, noncanonical forms, unknown definitions and rotations, repeated pages, excess capacity, truncated or trailing bytes fail decoding. The encoded form excludes runtime revisions, callbacks, resources and caches. The outer persistence system owns document binding, integrity and atomic publication.

Run the `gargantuan_blockgrid_field` CTest for signed addressing, bounded transactions, provider denial, value snapshots, canonical round trips and malformed-input cases.

## Creatable class and Main admission

The nullable saved `SpatialRegion` reference uses the existing generation-aware membership mixin. A grid can remain parented to Workspace while participating in its assigned chart. Runtime block revisions include the effective WorldRoot identity. Changing the explicit assignment revokes previous guards even when the original chart is later restored.

`Instance.new("BlockGrid")` creates an independent, empty grid with unit cells and identity pose. Configure `CellSize` to 0.5, 1 or 2 while empty. A proper rigid `CFrame` locates the local grid, and `Visible`, `CanCollide` and `CanQuery` govern the corresponding consumers. These five descriptor properties participate in ordinary persistence. The native cells have their own versioned codec. `BlockRevision` is a scoped read-only observation, excluded from saved and replicated properties.

After adoption, an authoritative offline or server creator can call `SetBlock`, `RemoveBlock`, `Fill` and `Clear`. The typed synchronous mutation command checks the current Main domain, actor capability, generation and DataModel identity. A changed edit advances the world revision and publishes one committed BlockRevision notification. A duplicate write preserves its revision. `GetBlock` returns a fresh definition/orientation table or nil. `ReadRegion` checks up to 4,096 positions and returns the captured revision and occupied cells in X-fastest order. `CellToWorld` returns a center; `WorldToCell` floors the inverse rigid transform in double precision. Network client cell reads require a future verified data projection and currently report unavailability.

`Grid:Raycast(Origin, Direction)` tests current queryable primitives independently of collision publication. World segment length must be 0.0001 through 100,000. A crossing advances all tied DDA axes and resolves equal hits by owner coordinate X, Y, Z then face. A ray starting strictly inside a primitive returns its first exit. A surface entry returns zero distance. Tangent-only contact has no interior. Segment traversal that exhausts 4,096 visits before determining the nearest hit raises a limit error. A hit contains a read-only cell, definition/orientation, world normal, world position and scoped revision.

## Primitive definitions

`Grid:DefineBlock("project:ramp", {Shape="Wedge"})` registers an immutable local descriptor and returns the grid revision. Names after `project:` start with a lowercase ASCII letter and contain up to 48 lowercase letters, digits, underscores or hyphens. A grid admits 1,024 custom bindings. The optional fields are Shape, Color, Collision, Queryable and Ports. Defaults select a white cube with Shape collision, a query volume and all six ports. An empty port array disconnects every face. Unsupported fields, duplicate ports and unresolved shapes raise errors before admission.

Use `ReplaceDefinition(Key, Spec, ExpectedGridRevision)` to change a binding while retaining cell identities and orientations. Installation precedes no observable callback until dependent provider capacity is admitted. The native reverse index stores up to 65,536 occupied definition-to-leaf links and limits a replacement to 1,024 affected leaves. Built-in-only occupancy has no index allocation. `GetDefinitionDigest` returns the 64 lowercase hexadecimal digits of the engine SHA-256 for canonical descriptor content. Definition and cell source changes share a scoped grid revision. Studio records authoring inverses for both.

Cube, Slab, Wedge and Stairs share a fixed catalog of 24 proper rotations about cell center. A local slab occupies the bottom half. A wedge rises toward +Z and fills Y ≤ Z. Stairs add the upper half of the back half to the lower slab. The catalog supplies outward triangles or quads, exact full-face coverage, and native collision pieces. The Box3D wedge's internal forward direction is converted in the collision piece orientation. Independent physical and query participation can retain a queryable shape with collision disabled.

Datasets containing definitions use BGRD version 2. Before the leaf count, a 16-bit count and ordered entries bind IDs 3 onward to key bytes, shape, three IEEE binary32 color components, collision/query flags and six port bits. The reader rebuilds reverse dependencies and validates finite colors, names, capacity and every bound ID before returning a field. Built-in-only grids retain the version 1 byte representation.

## State and ordered edits

A field can declare sixteen Bool, UInt8, Int32 or finite Float32 channels. A channel stores its shared default and allocates sparse immutable leaf values when occupied cells have overrides. Each value page is sorted by local cell index. The optional channel directory provides indexed traversal over nondefault pages. Default-valued writes release their entries. Common placement retains the uniform-leaf path while the grid has no overrides. The pilot caps nondefault values at 65,536 per grid.

Ordered operations stage occupancy and state together. Reorientation preserves values. Replacing a key removes overrides. A remove/reinsert command sequence resets values even when its resulting block key matches the original. Copy applies the channel's copy flag, while move preserves all state and includes air. Both read an immutable source slice for overlapping boxes. Native state-only writes advance the semantic revision and retain the geometry revision. Server-only changes also retain the public revision. Frozen snapshots share immutable value pages.

BGRD version 3 wraps the canonical geometry dataset with projected schema and nondefault values. Authored encoding includes persistent channels. ClientPersistent further restricts them to RelevantPeers. RelevantPeers includes both persistent and transient channels visible to clients. Clone preserves schema and only copies values for channels declaring OnCopy=Value. A projection with no eligible channel emits the original geometry bytes. Readback validates bound, occupied, unique ordered coordinates, scalar types and schema limits.

`BeginEdit` captures a scoped revision. Fill, clear, per-cell writes, value updates, transfers and packed images stage in call order. Enqueue failure closes the handle. Commit rechecks authority and revision and publishes one native transaction. Packed buffers contain little-endian one-based 16-bit palette indices in X-fastest order, with zero for air. The reader returns the cell dimensions, palette and per-key content digests. The writer validates and copies those inputs at enqueue.

`FindConnected` pins immutable cells, definitions and channel pages. It checks reciprocal rotated ports when requested and traverses face, edge or corner adjacency inside the supplied bounds. Each Step consumes the caller's budget on individual frontier emissions and neighbor probes. A discovered eligible cell beyond MaxVisited yields Limit. Exhausting the frontier at exactly the cap yields Complete. An indexed `FindActive` checks nondefault entries and skips disjoint pages. Terminal cursors release their pins. Scripts can continue reading the terminal status and empty result pages.

The VM admits four edits and four traversals per grid, up to 64 total handles, 64 MiB of conservatively charged pin memory per VM, and 128 MiB across VMs. Handles expire after five idle seconds or thirty seconds total. VM stepping, handle access, grid generation/domain changes and runtime shutdown release expired work. The server-side PoweredGate fixture in `tests/blockgrid/gameplay/PoweredGate.luau` demonstrates a four-cell circuit, a bounded connectivity proof, a guarded state change and a wire removal.

WorldRoot merges adjacent cubes with identical effective collision/query participation. Slabs and stairs use one or two oriented boxes per cell. Wedges use a native Box3D hull. An opted-in sphere, box or capsule overlap returns distinct grid cells with a pinned grid revision. Detailed pieces directly identify their cell. Merged cubes are subdivided in grid coordinates with the same Box3D convex overlap predicate and tolerance used by the world query. A result that proves one additional unique participant sets `Truncated`. Exhausting 32,768 refinement checks reports unavailability. With `IncludeBlockGrids`, the combined limit admits ordinary Parts in their existing order, then the Terrain owner, then grid cells. At equal nearest cast distance an existing Part or Terrain hit retains precedence.

## Project materials and static mesh definitions

The Material, Mesh and CollisionAsset fields accept a project asset's 32 lowercase hexadecimal digits or its asset URL. A primitive can use a whole Material override. A Mesh must select Collision="None" or Collision="Asset" and the latter requires the visual Mesh's actual imported Collision companion. A queryable mesh with collision disabled uses its visual surface only for picking and opted-in queries. Authored material slots preserve textures, UVs, tangent space, metallic/roughness, alpha mode, emission and submesh index ranges. A whole Material overrides each slot. Native mesh vertices occupy the centered unit cube before orientation and cell scaling. Skinning, out-of-cell vertices, undersized triangles, unready resources and mismatched roles reject the definition. A mesh's cell does not guarantee full coverage of any neighboring face.

A binding pins the sorted transitive project dependency closure by asset ID, kind and canonical SHA-256. Dataset version 4 extends version 2's descriptor flags with an optional role list and closure. The runtime resolves these pins against the adopting DataModel's AssetService before publication. A missing catalog, retired resource or different content makes the asset-backed grid unavailable. An explicit revision-guarded replacement accepts updated content. A matching refresh changes the provider geometry revision while preserving authored cells and their public revision. Version 3 channel envelopes may carry a version 4 base. Versions 1 and 2 retain their existing encodings. Initial AssetService snapshot hydration publishes the ordinary asset change sequence consumed by pending providers.

Each descriptor admits 64 transitive pins, 2,048 vertices, 1,024 triangles and 32 slots. Each grid admits 1,024 pin entries and conservatively charges up to 32 MiB of pinned descriptor and geometry storage. The renderer and collision provider share immutable asset buffers. The implicit visual query surface retains one position conversion per live vertex buffer. Source mesh rays visit up to 32,768 triangles in addition to their cell limit and follow Box3D's front-facing open-segment rule. Static native mesh bodies share their source triangles and rotate about cell center. World-space mesh geometry also respects the backend's 100,000-unit coordinate limit.
