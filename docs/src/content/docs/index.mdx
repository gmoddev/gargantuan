Gargantuan is an experimental C++23 game engine with Luau scripting, an
Instance/DataModel model and server-owned simulation. Familiar Roblox names
do not imply API or file-format compatibility.

Start with [capabilities and platform limits](./guides/getting-started/),
[build and run](./developing/working-on-gargantuan/) and
[your first project](./guides/first-project/). Existing Roblox projects need a
[compatibility review](./guides/roblox-deviations/).

## Choose a reference

- [Engine architecture](./developing/engine-architecture/): authority, identity,
  lifecycle, schema, scripting, assets and recovery.
- [Developer API](./api/): verified class/service behavior and checked examples.
- [Renderer](./developing/renderer/) and [physics](./developing/physics/):
  ownership, supported features and qualification limits.
- [Current networking](./developing/current-networking/): replication,
  admission, session lifecycle and the separate physical F1 gates.
- [Engine, Studio and Node](./developing/engine-studio-node/) and
  [EditorHost](./developing/editor-host/): LUI, Native Host and Engine boundaries.
- [Contributing](./developing/contributing-to-gargantuan/): source layout,
  conventions, testing and pull requests.
- [History and evidence](./developing/history/): retained decisions, receipts,
  the complete inventory and integration status.
