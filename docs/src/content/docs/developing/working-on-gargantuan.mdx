---
title: Build and run from source
description: Source-verified prerequisites, native test coverage and development commands.
---

Gargantuan uses C++23, CMake 3.25+, Ninja, generated Luau declarations and SDL GPU
shaders. Read the canonical [build guide](../../../../../devdocs/Compiling.md)
for platform prerequisites, options and qualification limits.

```sh
git clone --recursive https://github.com/gmoddev/gargantuan.git
cd gargantuan
rokit install
lute tools/classgen
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build --parallel 4
ctest --test-dir build -C Release --parallel 2 --timeout 300 --output-on-failure --no-tests=error
```

Install a supported compiler, Ninja, `clang-format`, Rokit and genuine `glslc`
before these commands. On Windows use the x64 Visual Studio 2026 developer
environment. Generate sources **before** configuring. Required CI covers Windows
Release and Linux Clang sanitizers; GPU and physical network tests remain
separate. macOS has no required CI gate.

From the repository root, `build/gargantuan --script=assets/examples/baseplate.luau`
opens the baseplate example. Use `build\gargantuan.exe` on Windows. The executable
also accepts `--project=samples/FirstCompleteGame` and `--headless`.
See [your first project](../../guides/first-project/) for creation and packaging.

`just test` runs only the legacy Luau core suite. Use CTest for native coverage
and the [CI contract](../../../../../devdocs/CurrentArchitecture/ContinuousIntegration.md)
for qualification. Documentation work uses [integrity checks](../../../../../tools/docs/README.md)
without reserving a native worker.
