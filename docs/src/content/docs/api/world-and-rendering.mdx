`Workspace` inherits `WorldRoot` and is the session's physical 3D world. A `Part` is a concrete `BasePart`; `MeshPart` renders a catalog mesh and has its own collision mode. Changes to live parts commit through the DataModel mutation path on Main. Physics consumes committed intents at safe points, then publishes owned results. The renderer consumes immutable extracted state, so a script does not hold or edit GPU objects.

## Parts and motion

`BasePart` declares `Anchored`, `CanCollide`, `CanTouch`, `CastShadow`, `Kinematic`, `CFrame`, `Position`, `Rotation`, `Size`, `Color`, `Transparency`, `CollisionGroup` (0–15), `CollisionMask` (16 bits), damping, `GravityScale`, `SleepEnabled`, and `MovingBodyCCD`. `Part.Shape` selects a primitive. `MeshPart.Mesh` is a strict Mesh asset reference, `Material` an optional Material override, and `CollisionMode` selects box or eligible anchored static mesh collision. Unanchored MeshParts use box collision. `Workspace.Gravity` defaults to 196.2 in the declaration.

`BasePart:ApplyImpulse(Impulse: Vector3)`, `ApplyAngularImpulse`, `ApplyImpulseAtPosition(Impulse, Position)`, `ApplyForce`, `ApplyTorque`, `SetLinearVelocity`, `SetAngularVelocity`, and `SetAwake` queue physical controls for a safe point or fixed step. `GetLinearVelocity()`, `GetAngularVelocity()`, `GetMass()`, `GetLocalInertia()`, and `GetAwake()` read the latest published state; mass is zero before body admission. `Touched(OtherPart)` and `TouchEnded(OtherPart)` are signals, not collision callbacks that authorize arbitrary cross-thread graph mutation. Rigid bodies and constraint handles are engine-owned; script identity is the Instance.

## Characters and semantic sockets

`Character` is a semantic actor with a saved `CFrame` and nullable `RootPart`.
The root must be a descendant `BasePart` in the same DataModel; setting a foreign
or unrelated root fails before commit. A rootless logical Character is valid.
`Character:Move(Translation, Velocity?)` requests collision-authoritative motion.
`KinematicCharacter` specializes the existing capsule primitive; its movement
selection, input, camera and action policy remain replaceable Luau. No Humanoid
or additional controller aggregate is required. Authoring an initial transform
does not grant a client authority to move another player's runtime Character.

`Attachment.CFrame` is a relative socket transform. A nonempty `JointPath` names
a canonical joint in an ancestor skinned MeshPart; `WorldCFrame` is a read-only
resolved semantic pose. An incompatible skeleton reimport invalidates its bound
pose until explicit socket reauthoring. A canonical path existing in inspection
does not establish a compatible live binding.

The advanced creator feature adds `AttachmentMesh`, an `Attachment` subclass
with saved, replicated visual properties. `Mesh` and optional `Material` use
strict asset references. Each `Size` component is finite 0.01–1024; linear
`Color` channels and `Transparency` are 0–1. `Visible` and `CastShadow` control
presentation. The rigid visual follows the socket's full semantic matrix,
including joint scale, without a collision body, touch/query identity or
movement authority. A skinned Mesh is not a rigid accessory. Invalid assets or
an unresolved socket omit the visual; they do not place it at an origin fallback.
The publication supports 1,024 visual attachments and omits all of them with an
incomplete diagnostic if that bound is exceeded. See
[Character authoring](../../guides/character-authoring/) for availability and setup.

## World queries

These `WorldRoot` methods are available on `Workspace` and require `ReadDataModel`. Results are owned values. A cast with no hit returns `nil`; an overlap with no matches returns a read-only `{ Parts = {}, Truncated = false }` result. Invalid dimensions, non-finite inputs, or resource limits can raise an error. `RaycastParams?` is optional. Query filters and detailed limits are implemented in `src/classes/WorldRootQueries.cpp` and `src/datatypes/RaycastParams.cpp`.

| Method | Parameters | Result |
| --- | --- | --- |
| `Raycast` | `Origin: Vector3, Direction: Vector3, Params: RaycastParams?` | Hit or nil. Direction magnitude is maximum distance. |
| `SphereCast` | `Origin: Vector3, Radius: number, Direction: Vector3, Params?` | Hit or nil; initial overlaps are ignored. |
| `CapsuleCast` | `Transform: CFrame, Radius: number, Height: number, Direction: Vector3, Params?` | Hit or nil; local Y axis, height includes caps. |
| `BoxCast` | `Transform: CFrame, Size: Vector3, Direction: Vector3, Params?` | Hit or nil. |
| `GetPartsInSphere` | `Origin, Radius, Params?, MaxResults?` | `{ Parts: {BasePart}, Truncated: boolean }`. |
| `GetPartsInCapsule` | `Transform, Radius, Height, Params?, MaxResults?` | Same overlap result. |
| `GetPartsInBox` | `Transform, Size, Params?, MaxResults?` | Same overlap result. |

A hit contains `Instance: BasePart`, `Position: Vector3`, `Normal: Vector3`, and `Distance: number`. `MaxResults` for overlaps is 1–256; test `Truncated` before treating the returned set as complete. Parts are returned in stable identity order. `MoveKinematicCapsule(Position, Radius, Height, Translation, Velocity)` returns a bounded collision-resolution table with `Position`, `AppliedTranslation`, `Velocity`, `ContactNormal`, `FloorNormal`, `Collided`, `HasFloor`, and `PlanesTruncated`. It is the primitive used by replaceable character movement policy, not a full character controller. See [the query example](https://github.com/gmoddev/Gargantuan/blob/main/docs/examples/world-query.luau).

The Engine advances world physics during its simulation phase. Luau controllers can queue body controls in `RunService.PreSimulation` and inspect completed simulation in `RunService.PostSimulation`.

Deformable inspection methods `GetDeformableInfo(Body)`, `GetDeformableVertex(Body, VertexIndex)`, and `GetSoftBodyStepInfo()` return bounded read-only snapshots or nil. `VertexIndex` is zero based.

## Frame timing and visible state

`RunService.PreSimulation(DeltaTime)`, `PostSimulation(DeltaTime)`, and `PreRender(DeltaTime)` are signals. `PreRender` runs before extraction/publication; a committed camera or visual change made there can affect the next publication. This is not a general render-thread callback. Keep handlers bounded, and disconnect connections when their owning gameplay object is removed.

`Workspace.CurrentCamera` is a read-only reference managed by the engine. `Camera.CFrame` and vertical `FieldOfView` (1–120 degrees) are script-facing authored view state; `ViewportSize` is engine-written. `Lighting` has authored `Ambient`, `SunColor`, `Brightness`, `ClockTime`, `ExposureCompensation`, `EnvironmentColor`, `FogEnabled`, `FogColor`, `FogStart`, and `FogEnd`. A `Sky` or `MeshPart` needs valid catalog assets for its intended visual result.

The integrated `Lighting` declaration also exposes these authored controls. Invalid or non-finite values raise a property error before commit.

| Property | Accepted value | Effect |
| --- | --- | --- |
| `ShadowCascadeCount` | Integer 0–4; default 0 | Zero keeps the existing fixed directional shadow volume; 1–4 request camera-relative cascades. |
| `ShadowDistance` | Number 1–4096; default 250 | Maximum camera-relative directional shadow coverage. |
| `EnvironmentRotation` | Degrees -180–180; default 0 | Yaw of the visible Sky and its image-based lighting. |
| `IblIntensity` | Number 0–8; default 1 | Linear multiplier for diffuse and specular image-based lighting. |
| `ToneMapping` | `Enum.ToneMappingMode.Filmic` or `.Reinhard`; default Filmic | Maps exposed world color before GUI composition. |

## Local lights and reflection probes

`LocalLight` is abstract. Construct `PointLight` or `SpotLight` with `Instance.new`, then parent it under `Workspace` or beneath a `BasePart` in that WorldRoot. `LightCFrame` is a rigid pose relative to the nearest ancestor `BasePart`, or in WorldRoot coordinates without one. `LightEnabled` defaults true; `LightColor` has linear RGB channels in 0–1; `LightIntensity` is 0–4096 and `LightRange` is 0.01–1024 world units. `SpotLight.LightConeAngles` is `Vector2.new(Inner, Outer)` in half-angle degrees, with `0 <= Inner <= Outer` and `1 <= Outer <= 89`; it points along the negative Z axis of `LightCFrame`. `LightShadows` requests shadows and `LightShadowPriority` ranges from -1024 to 1024. These are ordinary authored Instance properties subject to DataModel mutation authority. See [the light example](https://github.com/gmoddev/Gargantuan/blob/main/docs/examples/local-light.luau).

The renderer publishes at most 512 enabled, nonzero-intensity local lights from one WorldRoot; the SDL light grid admits at most 24 overlapping lights per screen tile. `LightShadows` is a request, not a guarantee: the current SDL path has eight admitted spotlight shadow layers, while point-light shadow requests remain unshadowed. Lights with invalid world transforms or beyond publication capacity are skipped. The light and its transform are source data; the renderer owns shadow maps and other GPU resources.

`ReflectionProbe` is a constructible local environment source, not an automatic scene capture. Parent it under `Workspace` or beneath a `BasePart` there. `ProbeCFrame` is a rigid relative pose, `ProbeSize` is the full oriented influence-box size (each component 0.1–16384), and `ProbeCaptureOffset` must stay strictly inside that box. `ProbeBlendDistance` is 0–8192; `ProbeIntensity` is 0–8; `ProbePriority` is an integer -1024–1024; `ProbeEnabled` and `ProbeBoxProjection` are booleans. Supply `ProbePositiveX`, `ProbeNegativeX`, `ProbePositiveY`, `ProbeNegativeY`, `ProbePositiveZ`, and `ProbeNegativeZ` as six available square, equal-size Image asset references. Assignment checks reference syntax; publication checks actual Image kind and coherent dimensions. An incomplete probe contributes nothing and the global Sky remains independent.

Publication inspects at most 256 enabled probes and publishes at most 32 coherent ones; the SDL renderer keeps at most 12 resident and samples at most two per pixel. Preparation is bounded and may lag source changes, with other probes or the global Sky providing the environment while a probe is unavailable. These limits describe the current adapter, not a script-visible GPU API. Imported material textures, native mip views, Sky prefiltering, and shadow resources are renderer-owned derivatives. The rendered result can lag live authoritative state by a publication/frame boundary.
